# v0.6.1版本说明

本版基于 `v0.6.0` 沿用现有引擎，集中推进引擎底盘稳定性、SAF 文件访问边界、背景图层渲染顺序及应用内「关于」页链接同步；不包含游戏文件或玩家存档。

## 改了什么

- **目录与路径解析稳定性**：修复目录枚举与路径末尾分隔符处理，统一目录缓存失效键，并继续保持精确名称优先、大小写/Unicode 等价唯一回退、多候选歧义拒绝及写路径约束。
- **多背景图渲染顺序与裁切定位**：背景图层改为按 `depth` 从大到小稳定排序（显式保留同深度原始顺序，兼容较旧 Chromium 61 排序语义），渲染列表使用无冲突键，并将背景图裁切定位设为居中偏上（`object-position: center top`）。
- **SAF 文件访问与 SQL 边界**：
  - `SQL_IMPORT_MAP_XML` 改经 `SafCompat` 路径解析与流式读取，打通 SAF 内存库 XML 导入并阻断越界路径；
  - 在 SAF `content://` 模式下遇到相对文件型数据库时显式拒绝，避免拼接畸形本地路径（`:memory:` 内存库不受影响；持久化 SAF 文件型数据库留待后续专项设计）；
  - `LOADTEXT` 与 `SAVETEXT` 实行读写权限分离：`LOADTEXT` 允许读取游戏根下合法子目录（兼容 eraTW 数据/脚本文件），`SAVETEXT` 收紧至仅允许写入游戏根或 `sav/` 子目录并保留路径穿越防护。
- **应用内「关于」页同步**：将内置「关于」页的开源仓库与 Releases 入口统一更新为当前公开稳定仓 `https://github.com/xiangweilai258/EraRelay`。
- **测试隔离与回归网**：修复同进程并行测试的共享静态路径/配置隔离问题并补齐 SAF 与 SQL 回归测试，本版自动化测试网达成双端全绿。

## 范围与已知限制

音乐与游戏内 Bad Apple 动画明确暂不适配；快速施法／输入宏完整链、部分图形像素能力及后续性能优化批次不在本版范围。主要面向 eraTW 画蛇添足版，其他游戏未全面验证，不宣称全量插件兼容、量化提速或零缺陷。

### 已验

- **引擎自动化**：`EraCore.Tests` 同进程默认并行全量连跑 2 轮均为 **1477/1477 通过**（0 失败 / 0 错误 / 0 超时，独立隔离测试 AppData 与本地回环直连）；`EraCore.Maui.Tests` **29/29 通过**。
- **包体静态核验**：Android APK 签名（v1/v2/v3）、历史同证书连续性、16KB ZIP 与原生 ELF 加载段对齐、SQLite 2.1.12 原生库逐字节一致、双端包内 5 份前端资源与本次构建逐字节一致、Windows ZIP 逐条目解压回读校验与有限模式隐私扫描均通过。

### 未验
